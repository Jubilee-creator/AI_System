# /ship

Purpose:
Prepare work for production, deployment, or client delivery.

Use when:
Samuel is done building or editing and wants to finalize, clean, and verify everything before shipping.

---

## PRE-SHIP CHECK

1. Code Quality
- Is code clean and readable?
- Any obvious bugs?
- Any broken components?

---

2. UI + UX
- Does it look premium?
- Is spacing consistent?
- Is layout clean on desktop AND mobile?

---

3. Functionality
- Do buttons work?
- Are links correct?
- Any missing sections?

---

4. Performance
- Remove unnecessary code
- Avoid heavy components
- Check for obvious slow areas

---

5. Consistency
- Fonts consistent
- Colors consistent
- Buttons consistent
- Layout aligned

---

6. Security / Safety (if applicable)
- No exposed keys
- No sensitive data
- No dangerous actions

---

## FINAL OUTPUT

1. SHIP VERDICT
- ready / not ready

2. FIXES NEEDED
- list issues if not ready

3. IMPROVEMENTS
- optional upgrades

4. FINAL NOTES
- what to test after deployment
- anything to watch for

---

## RULES

- Do NOT overbuild
- Do NOT redesign everything
- Focus on readiness, not perfection

---

## QUALITY CHECK

Before finishing:
- Would I send this to a real client?
- Would I deploy this live?
- Does anything feel unfinished?
