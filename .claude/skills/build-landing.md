# /build-landing

Purpose:
Build a premium, high-converting landing page for a client, product, or business.

Use when:
Samuel asks to build a landing page, homepage, product page, offer page, service page, or client site.

---

## PROCESS

1. Identify the offer:
- What is being sold?
- Who is the target customer?
- What problem does it solve?
- What action should the visitor take?

2. Build page structure:
- Hero section
- Problem section
- Solution section
- Benefits section
- How it works / process
- Social proof / trust
- FAQ section
- Final CTA

---

## DESIGN RULES

- Mobile-first always
- Premium minimal design (Apple / Dyson level)
- Strong spacing and layout hierarchy
- Clean typography
- High contrast for readability
- Motion only when it improves clarity
- No generic AI template look
- Conversion > aesthetics

---

## COPY RULES

- Clear, simple, direct language
- Focus on benefits, not features
- Speak to the customer's problem
- Strong call-to-action
- No fluff or buzzwords

---

## OUTPUT

- Structured sections
- Clean layout
- Code when requested (Next.js + Tailwind)
- Explain what was built
- Mention what still needs assets (images, copy, etc.)

---

## QUALITY CHECK

Before finishing:
- Does it look premium?
- Does it clearly communicate value?
- Would a real customer understand it fast?
- Does it push toward conversion?
