# /polish-ui

Purpose:
Upgrade UI from average → premium, modern, and high-converting.

Use when:
Samuel asks to improve design, clean UI, or make something “look better” or more professional.

---

## PROCESS

1. Inspect current UI:
- spacing issues
- clutter
- weak hierarchy
- inconsistent styles
- poor readability

2. Identify what feels “cheap”:
- generic layout
- bad font usage
- inconsistent spacing
- too many colors
- no visual flow

---

## DESIGN UPGRADE RULES

### Layout
- Use consistent spacing (padding + margins)
- Create clear sections
- Use whitespace intentionally
- Avoid clutter

### Typography
- Limit to 1–2 fonts max
- Strong hierarchy (H1, H2, body)
- Increase readability
- Avoid tiny or crowded text

### Color
- Limit color palette
- Use high contrast
- Use color for emphasis only (CTA, highlights)
- Avoid random gradients unless brand fits

### Components
- Consistent button styles
- Consistent card styles
- Clean inputs/forms
- Align everything properly

---

## PREMIUM FEEL (CRITICAL)

- Apple/Dyson-level minimal design
- Clean, modern, intentional
- Nothing feels random
- Everything has purpose

---

## MOTION (WHEN NEEDED)

- Add subtle animations:
  - hover effects
  - smooth transitions
- Do NOT overuse animation
- Motion should improve clarity, not distract

---

## WHAT TO REMOVE

- generic AI look
- unnecessary sections
- visual noise
- inconsistent styling

---

## OUTPUT

- Improved layout structure
- Cleaner design decisions
- Updated code if needed
- Explanation of what changed and why

---

## QUALITY CHECK

Before finishing:
- Does it look premium?
- Is it clean and easy to scan?
- Does it feel intentional?
- Would a real brand use this?
