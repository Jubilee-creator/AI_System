# /handoff

Purpose:
Create a clean transfer summary for continuing work in a new chat or session.

Use when:
Chat is getting long or moving to a new session.

---

## INCLUDE

1. CURRENT STATE
- What has been built

2. KEY DECISIONS
- Important choices made

3. WHAT WORKS
- Confirmed working parts

4. WHAT IS BROKEN
- Known issues

5. NEXT STEP
- Exact next action

6. IMPORTANT RULES
- Constraints to follow

---

## RULES

- Do NOT invent info
- Only include what was discussed
- Keep it clear and structured
